# Manual de Usuario - AI Guardian

Esta guía explica cómo instalar y usar el plugin AI Guardian en tu sitio WordPress.

## Instalación

1. Copia la carpeta del plugin en `wp-content/plugins`.
2. Activa **AI Guardian** desde el panel de *Plugins*.

## Uso Básico

Tras activar el plugin encontrarás un nuevo menú llamado **AI Guardian**. En esta versión inicial solo muestra un panel vacío preparado para futuras funcionalidades.
