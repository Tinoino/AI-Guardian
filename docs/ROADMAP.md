# Roadmap AI Guardian

## MVP
- Estructura básica del plugin y dashboard sencillo.
- Integración inicial con fuentes de vulnerabilidades.
- Configuración de CI/CD.

## Beta
- Escáner de seguridad completo con detección de XSS, SQLi y CSRF.
- Integración con WAF externo para bloqueo en tiempo real.
- Sistema de alertas y logs forenses.

## Release
- Optimización de rendimiento con caché y análisis de consultas.
- Internacionalización completa y panel en React.
- Actualizaciones automáticas del modelo de IA y del plugin.
