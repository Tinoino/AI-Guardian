# AI Guardian

AI Guardian es un plugin para WordPress que utiliza técnicas de inteligencia artificial y aprendizaje automático para mejorar la seguridad y el rendimiento de tus sitios. Esta es una versión inicial que contiene la estructura básica del plugin y un panel de administración sencillo.

## Características

- Arquitectura modular preparada para integrarse con distintos proveedores de IA.
- Panel de administración en el escritorio de WordPress.
- Preparado para internacionalización (i18n).

## Requisitos

- PHP 8+
- WordPress 6+

## Instalación

1. Clona este repositorio dentro de la carpeta `wp-content/plugins`.
2. Activa el plugin desde el panel de administración de WordPress.

## Documentación

Consulta los manuales en la carpeta `docs/` para más información sobre la configuración y uso del plugin.
